The funniest one-line excuse a robot vacuum can give for missing a spot, in 200 characters or fewer: deadpan, a little smug about its sensors and its warranty, with the punch at the end. A comedy judge compares the lines two at a time and picks the one that lands hardest.

## Run it

```sh
node main.ts
```

The program writes a single line (154 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
